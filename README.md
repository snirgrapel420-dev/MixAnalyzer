# Production Analyzer

פלאגין VST3 / AU לאבלטון שבודק את המיקס לפני שליחה למאסטר ומסביר בעברית מה לתקן.

## בנייה

דרישות: CMake 3.22 ומעלה, ו-Xcode (Mac) או Visual Studio 2022 (Windows). את JUCE 8 ה-CMake מוריד לבד.

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

ב-Windows אפשר גם: `cmake -B build -G "Visual Studio 17 2022"` ואז לפתוח את ה-`.sln`.

הפלאגין מועתק אוטומטית לתיקיית הפלאגינים:

* Mac VST3: `~/Library/Audio/Plug-Ins/VST3/`
* Mac AU: `~/Library/Audio/Plug-Ins/Components/`
* Windows VST3: `C:\Program Files\Common Files\VST3\` (דורש הרצה כמנהל, או העתקה ידנית מ-`build/ProductionAnalyzer_artefacts/Release/VST3`)

באבלטון: Preferences → Plug-Ins → Rescan.

## שימוש

1. שימו את הפלאגין **אחרון** על ערוץ ה-Master. אם יש לימיטר להאזנה בלבד, עקפו אותו.
2. בחרו סגנון מוזיקלי. הוא משנה ספים של לואו-אנד ודינמיקה.
3. "התחל ניתוח", נגנו את כל הטראק, ואז "עצור והפק דוח".
4. או "טען קובץ אודיו" לניתוח קובץ WAV/AIFF/FLAC/MP3 של המיקס, בלי לנגן.
5. "ייצא דוח" או "העתק דוח" כדי לשלוח את הממצאים למהנדס המאסטר.

## מה נבדק

| בדיקה | איך נמדד |
|---|---|
| Headroom ועוצמה | True Peak (אינטרפולציה פי 4), Integrated LUFS ו-Short-term לפי ITU-R BS.1770 |
| קליפינג | רצפי דגימות על 0dBFS, דגימות מעל 0 (float), Inter-sample peaks, "ראשים שטוחים", DC offset |
| קיק ובאס | זיהוי מכות קיק בתחום הנמוך, השוואת ספקטרום ברגעי מכה מול בין המכות: תדר קיק, תדר באס, פאנץ' |
| Low-end | סטייה של 25–125Hz ושל 160–400Hz מקו המגמה הטונאלי של המיקס עצמו |
| פאזה | קורלציה כללית, קורלציה מתחת ל-150Hz, אחוז זמן עם קורלציה שלילית |
| מונו | איבוד עוצמה בסיכום למונו, כללי ולפי תחומי תדרים |
| איזון סטריאו | L/R כללי ולפי תחומים, אחוז זמן לא מאוזן, סטריאו מתחת ל-120Hz |
| צרימה | סטייה של 2–5kHz ו-6–10kHz, קפיצות רגעיות |
| רזוננסים | פיקים צרים (1/6 אוקטבה) מול סביבה של אוקטבה, עם שם התו |
| מיסוך | מדד משוקלל: בוץ, צפיפות ספקטרלית, ריכוז במרכז הסטריאו, התנגשות קיק ובאס |
| צפיפות ספקטרלית | Spectral flatness, שיפוע טונאלי, חורים בספקטרום, Centroid |
| טווח דינמי | PLR ו-LRA (EBU Tech 3342) |
| Crest factor | פיק מול RMS (מסונן משקט) |

המנוע נבדק על אותות סינתטיים: סינוס 997Hz ב-20- dBFS נמדד בדיוק 20.00- LUFS, רעש ורוד נותן שיפוע 0, וערוץ הפוך מזוהה כקורלציה 1-.

## התאמה אישית

* **עיצוב**: כל הצבעים, הפונטים והמרווחים ב-`Source/Theme.h` בלבד.
* **ספים לפי סגנון**: `kProfiles` בראש `Source/ReportBuilder.cpp`.
* **טקסטים וטיפים**: פונקציות `check...` ב-`Source/ReportBuilder.cpp`.

## בדיקת המנוע בלי JUCE

```bash
cd tests
g++ -std=c++17 -O2 -I../Source engine_test.cpp ../Source/AnalysisEngine.cpp ../Source/ReportBuilder.cpp -o engine_test
./engine_test
```
